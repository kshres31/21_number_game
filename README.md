# 21 Number Game

A terminal-based implementation of the classic 21 Number Game in Python.

Two players take turns counting from 1 to 21. On each turn, a player must call
between 1 and 3 consecutive numbers. Whoever is forced to say **21 loses**.

## Setup

Requires Python 3.8 or higher.

```bash
python main.py
```

## Testing

```bash
pytest
```
